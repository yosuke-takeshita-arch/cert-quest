# CC0 の音を探して、選んでもらって、組み込む

正本: `docs/sources/audio-licenses.md`（ライセンスの記録と決まり。ここに1行足さないと `shared/tests/sound.test.js` が落ちる）、`shared/js/lib/sound.js`（BGM・効果音の表と音量の補正）。

## 決まり
- **CC0 だけ**（リポジトリは公開されていて、音のファイルは誰でも取り出せる）。CC-BY・OGA-BY・GPL などは不可。併記で CC0 を選べるものはよい（記録に書く）
- 配布ページ（Kenney は zip の中の License.txt）を **curl で取得して、取得した中身で** License(s) 欄が CC0 であること、Attribution を求める記載が無いことを確かめる（WebFetch の要約で決めない）。Attribution 欄に名前やサイトだけが書いてあって、求めているか判別できないものは外す
- 特定のゲームの曲・音そのもの、その模倣やリメイクは使わない
- ほかの場面ですでに使っている音は候補にしない（場面で音を分ける）

## 手順
1. **候補を集める**（担当に出す。general-purpose。音は聞けないので、タグ・説明と数値で選ぶ）
   - 配布元は OpenGameArt.org と Kenney を第一に。6〜8個
   - 記録: 配布ページの URL・作者・ライセンス欄の逐語・Attribution 欄の逐語・タグ・長さ・大きさ・形式（zip の中なら元のパス）
   - ファイルは作業場所（scratchpad）に取る。リポジトリには置かない
   - 先生の言葉で「重い」「低い」などの希望が出たら、ffmpeg で周波数の重心・低音の割合を測って並べる（2026-10-09「もっと重たいどん！」）
2. **門番が2〜3件、配布ページのライセンス欄を自分で取り直して見る**
3. **先生に聞いてもらう**
   - 配布ページで1曲ずつ再生できるものは、ページのリンクを表で渡す
   - zip の中の1ファイルなど、ページで個別に聞けないものは、mp3 に変換して（iPhone は ogg を鳴らせないことがある）SendUserFile で送る
   - Artifact の聞き比べページに音のファイルを載せようとすると、読み取りの許可設定で止められた（2026-10-09）。回避しない
   - 「ひとこと」はタグと説明から書いたもので、聞いた感想ではないと明記する
4. **組み込む**（担当に出す。frontend-designer）
   - 配布ページを取り直し、原本と cmp で一致を確かめる
   - 大きい BGM は ffmpeg で 128kbps の mp3 に。効果音は元の形式のまま（ogg でよい。今の効果音と同じ鳴らし方）
   - 音量: BGM は decodeAudioData で rms・peak を測って `trim` を決める（sound.js のコメントの測り方）。効果音は補正なしで、ほかの効果音との大きさの差を報告する
   - ファイルが読めないときは、今までの音（プログラムの音など）に戻す
   - `audio-licenses.md` に1行（元のファイル名・変換・長さ・バイト数・確かめた逐語・確かめた日・先生が聞き比べて選んだこと）
   - 効果音は `sw-core.js` の `SFX` で先取り。BGM は初めて流したときに取る
5. **公開**（→ cert-quest-publish）。実機の聞こえ方は先生に確かめてもらう

## 道具
ffmpeg は作業場所で `npm i ffmpeg-static`（`node_modules/ffmpeg-static/ffmpeg.exe`）。
