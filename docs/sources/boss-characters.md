2026-10-09 作成。要件定義書 §3-7「ボスの設定」の正本。G検定10体・DXビジネス検定13体・生成AIパスポート32体（2026-10-13 追加）、合わせて55体。これとは別に、G検定の真ボス（要件定義書 §3-9。3つの形態をもつ1体）を「G検定」の節の最後に置いた（2026-10-23 追加）。同じ日に、DX の真ボス「ヘンカクジン」と生成AIパスポートの真ボス「アマツクリ」を、それぞれの節の最後に足した。

- 画面に出すのは、名前とせりふだけ（g-kentei/data/bosses.json・dx-biz/data/bosses.json・ai-passport/data/bosses.json）。性格・見た目・好き嫌いなどは、絵を作るときと、せりふを足すときの拠り所で、今は画面に出さない。
- 番号は地図の章の並び（syllabus.json の大項目→中項目の順）。絵のファイル名 boss-<番号>.webp と同じ番号。
- 絵のプロンプトは docs/sources/art-prompts.md の「ボス」の節。見た目はこのファイルと合わせる（変えるときは両方直す）。
- せりふの決まり: 1つ30字以内。昔の RPG 風に、ひらがな多め・短く。怖すぎず、暴力的な言葉・差別的な言葉は使わない。攻撃のせりふは先生が間違えたとき、ダメージのせりふは正解したときに出る。
- せりふに試験の中身を入れたものは、行の後ろに【照合】として照らしたカードの ID を書いた（カードの oneLine と食い違わないことを確かめた）。【照合】の無い行は、試験の中身を言っていない。
- 名前は造語にした。実在の人物・商標・既存のゲームのキャラクター名と同じにならないよう選んだが、商標の登録や全てのゲームまでは検索で確かめていない。公開の前に気になる名前があれば差し替える。
