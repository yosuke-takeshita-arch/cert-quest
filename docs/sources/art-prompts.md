# 絵のプロンプト（ChatGPT に渡す）

## ボス（章のボス戦・要件定義書 §3-7）

2026-10-09 全身の絵に作り直した（先生の言葉「ファミコンのドラクエのようなイメージ。よってボスは全身が必要。」）。見た目・色・性格は docs/sources/boss-characters.md が正本。ここを変えるときは、あちらも直す。

- 置き場: G検定は g-kentei/images/bosses/boss-<番号>.webp、DX は dx-biz/images/bosses/boss-<番号>.webp。番号は地図の章の並び（1から）で、下の見出しの番号と同じ。置くだけで記号と入れ替わる
- 使い方: 戦いの画面では全身を大きく出す。章の画面・地図では、絵の上のほう（顔）を直径 56〜88px の丸に切り抜いて出す。だから顔が上3分の1に来る構図にしてある
- 1体ずつ、下の枠の文を丸ごと ChatGPT に貼る（どの枠も、それだけで完結している）
- 絵柄: 明るいファンタジーのアニメ調の全身（2026-10-09 先生決定。ドット絵にはしない）。23体とも同じ絵柄にそろえる
- 背景（2026-10-09 先生の提案で変更。4体目から）: 透過をたのむと ChatGPT は市松模様を描き込むことがあるので、絶対に使わない色でべた塗りしてもらい、門番がその色だけを消す（tools/chromakey.cjs）。ふつうはマゼンタ #FF00FF。体がマゼンタに近いタタミメ・ウツシミ（G検定）・サブスクリュウ・デタコ（DX）は緑 #00FF00（node tools/chromakey.cjs 元.png boss-N.webp 512 green）。キーの色が体に入っていると体も消えるので、プロンプトで「キャラクターにその色を使わない」とたのんである
- 背景が透過にならず黒で出たときも、そのまま置いてよい（戦いの画面は黒い背景）
- 背景に市松模様（白と薄い灰色のます目）が描き込まれて出ることがある（透過に見えるが透過ではない）。門番が tools/unchecker.cjs（外周からつながる白・薄い灰色だけを透過にする）で抜く（2026-10-09、boss-2）
- 顔が絵の真ん中に無いとき（竜の横向きの体など）は、<アプリ>/data/bosses.json のそのボスに "face": { "x": 0.42, "y": 0.29 }（顔の中心の、幅と高さに対する割合）を足すと、小さな丸の切り抜きが顔に合う。無ければ x 0.5・y 0.23
