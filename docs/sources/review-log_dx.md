# DXビジネス検定 覚え方（memoryTip）の見直し記録

2026-10-04。全307問の `memoryTip` を、問題文・選択肢・正解・解説・`whyWrong` と合わせて1問ずつ読み、悪い覚え方の型に当たるものだけを書き直した。触ったのは `memoryTip` の行だけ（HEAD と行単位で比べ、他の行の差分が0であることを機械で確かめた）。

- 型：1 たとえ・標語だけで中身が残らない／2 問題文や正解の言い換えだけ／3 間違えやすい選択肢との区別に役立たない／4 たとえ・説明が不正確／5 語呂が無理やり
- 1問が複数の型に当たるときは、いちばん大きい理由を1つだけ書いた
- 書き直しの中身は、その問題の解説・`whyWrong`・同じ章の他の問題の解説に書いてある範囲に限った

## 直さなかったが記録しておくもの

- D-07-010・D-07-028・D-10-013：覚え方はロックインの型（コミュニティ・ブランド）の定義を言い切っているが、紐づくカード（DC-07-019・DC-07-021）は `unverified`。問題そのものが同じ定義を正解の根拠にしているため、覚え方だけ弱めても意味が無いと判断して残した。カードの出典確認が済むまで保留。
