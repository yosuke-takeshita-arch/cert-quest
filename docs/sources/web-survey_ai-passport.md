## 0. 結論（先に書く）

1. **公式は、4つの選択肢から選び、一部に複数選ぶ問題がある、と3か所で書いている。** 試験概要ページの出題方法、サンプル問題 PDF の表題、特設ページの出題イメージ（逐語は §1）。同じ特設ページの AIクイズアプリの注意書きだけが複数選択に触れずに書いているが、これは ○✕ 形式のアプリとの違いを言う文脈の文である（この読みは私の推定で、公式の説明ではない）
2. **複数選択の問題の実物は、公式には1つも無い。** 公式の例題は3問とも1つを選ぶ問題。何個選ぶかを問題文で示すのか、すべて選ばせるのか、部分点があるのかは、公式資料からは分からない。受験記（No.16、受験日は 2024年6月21日で、いまのシラバスより2つ前の版のころ）に、複数選択の問題も一部出た、という記述がある。言い回しは書かれていない（筆者は GUGA の禁止事項を理由に開示しないと書いている）
3. **公式の例題の言い回し:** 問題文は3問とも「を１つ選びなさい。」で終わる。最も、の語は付けない。3問中2問が、不適切なものを1つ選ばせる形（例題2・3）。選択肢は ①〜④ の丸数字で、用語4つの形（例題1・2）と文4つの形（例題3）がある
4. **Web の問題は、ほぼすべて旧シラバス（2026年2月〜10月試験）を元にしている。** アプリが使う 2027年2月試験からのシラバスでは語が消えた論点（強いAI／弱いAI、AIの4つのレベル、BERT、Code Interpreter・GPTs、QRコード・公衆Wi-Fi など）が、Web では繰り返し出る。§3 の表の右端の列で分けた
5. **重点の論点（2つ以上の運営元に出たもの）の数:** 第1章 15（うち 2027-02 のキーワードに無いもの 2）／第2章 11（同 1）／第3章 5／第4章 19／第5章 8

### 1-2. 公式の形式から読み取れること（私の読み。公式の説明ではない）

- 誤答の作り方が3問で違う。例題1は**学び方でないもの（過学習）を学び方の選択肢に1つ混ぜる**。例題2は**生成AIの限界（正確さは保証されない）を、できることの側に置く**。例題3は**正しい文3つに、言い過ぎの文（厳格に法律で規制されている）を1つ混ぜる**
- 用語を選ぶ問題でも、問題文は用語の説明そのもの（例題1）。説明文の言い換えから用語を当てさせる
- 複数選択の問題をアプリで作るかは、要件定義書 §11-1 の判断のまま。公式に実物が無いので、作るなら問題文で選ぶ数を示す形が無難だが、これは公式で確かめられていない
