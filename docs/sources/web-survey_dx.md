# DXビジネス検定 Web上の問題の調査メモ（作成日 2026-10-02）

> **注意:** このメモはオリジナル問題を作るための材料である。**アプリや問題の sources には出さない。**
> **問題文・選択肢は写していない。論点の抽出のみ**（論点・ひっかけの型・混同の組み合わせを自分の言葉で要約した）。
>
> **確かめ方の区別:**
> - 【原文で確認】… curl で HTML / PDF を取得し、本文を grep して読んだもの（公式2ページ、銀行業務検定のサンプルPDF）
> - 【要約のみ】… WebFetch（小型モデルの要約）で読んだもの。論点の拾い方は概ね信用できるが、**細部（番号・件数・年月）は誤りうる**。実際、公式ページの WebFetch 要約は公式テキストを「2026年6月改訂版」と返したが、原文は「2026年2月改訂」だった
>
> **調査の結論（先に書く）:** DXビジネス検定**そのもの**の問題を無料で公開しているWebページは、**公式のサンプル5題しか見つからなかった**。対策サイトの多くは試験概要の解説で、問題は載せていない。一問一答・模擬の実体があったのは、**近い検定**（旧DX検定＝現 DX Next検定、全日本情報学習振興協会のDX検定群、銀行業務検定 DXビジネスデザイン）と、DXビジネス検定向けアプリの**説明文**である。重点論点の出現数は、これらを合算して数えている。
