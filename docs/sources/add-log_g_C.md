## 確かめ方

- 原文は `curl`（User-Agent 付き）で取得し、PDF は `pdftotext -enc UTF-8`、HTML はタグを除いてから全文検索した。WebFetch の要約は根拠にしていない
- 法令は e-Gov 法令API（v1、`https://laws.e-gov.go.jp/api/1/lawdata/<法令ID>`）で本則の XML を取得し、条の見出し（ArticleCaption）と本文を確かめた。条番号はそれで確かめたものだけ書いた
- 説明も問題も索引の用語名から書き起こしたオリジナル。市販本の文は使っていない
- `verified` は、答え（不適切を選ぶ問題では、適切とされる選択肢も）の根拠を原文で見つけたものだけ
- links は自分の章のカードと、作業開始時に既にあったカードにだけ張った。A・B が新しく作るカードには張っていない

### 表から変えたもの

- 人間中心のAI社会原則: 表の「内閣府」の当てどおり内閣府掲載の決定文を使った（`www8.cao.go.jp/cstp/aigensoku.pdf` は404、`www8.cao.go.jp/cstp/ai/aigensoku.pdf` が正しい場所）
- EU AI法: 表の当ては EUR-Lex の原文だが、EUR-Lex が自動取得に 202（空の応答）を返して取れなかった。代わりに欧州委員会の公式ガイドライン2本（条文を逐語で引用している）で、第5条第1項(a)・第3条第63号・第51条第2項の中身を確かめた。EUR-Lex の原文そのものは開けていない
- ELSI: 表の当ては JST RISTEX のページだが、URL が404。内閣府「Society 5.0」のページに ELSI の定義（倫理的・法的・社会的な課題）があったのでそれを使った
- トロッコ問題: 表の当ては Awad 2018（Nature）だけだが、本文は有料で抄録しか読めず、トロッコ問題の型の説明が無かった。トロッコ問題そのものの説明は、同じ著者らの Awad 2020（PNAS、オープンアクセス、Moral Machine の「Classic」モードのデータ）で確かめた。Thomson 1985 の原典（Yale Law Journal）は取得できなかったので出典にしていない
- アルゴリズムバイアス・電力消費・AIとの協働・AIポリシーの「問題を足す」4件: 既存の問題（G-10-011〜015、G-10-028〜031、G-10-035〜037）と論点が重ならないよう、AI事業者ガイドラインの別の記述（回避できないバイアスの評価、計算量、フィジカルAI、ゴールの公開）から作った
- Value Sensitive Design: VSD Lab のページは提唱者の名前を本文で明示していないため、カードに提唱者名は書いていない
